## What it does

KSA Control Center is a standalone launcher and mod manager for Kitten Space Agency. It can launch KSA, manage a user-selected mod loadout, back up mods and `manifest.toml`, and link to authors’ original GitHub releases. On Linux, it offers an Intel Arc launch profile that uses Mesa’s Intel Vulkan driver and FIFO presentation mode when available.

**Platform note:** Only the Linux version has been tested on Fedora with an Intel Arc A750. The Windows portable build is available but remains untested.

## Mod catalog and attribution

KSA Control Center is **not a modpack**. It does not bundle or re-host other authors’ mod files. Each optional catalog install downloads the author’s original pinned GitHub release. Catalog sources, preview-image attribution, and third-party license notes are listed in [THIRD_PARTY.md](../THIRD_PARTY.md).
