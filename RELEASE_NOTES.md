# KSA Control Center v0.2.1

**Launch KSA. Discover community mods. Protect your loadout.**

> [!CAUTION]
> **Only the Linux version has been tested on a real PC. The Windows version is an untested portable build.**

## Downloads

- **Linux:** `KSA Control Center-0.2.1.AppImage`
- **Windows:** `KSA Control Center 0.2.1.exe` (portable x64 executable)

The Windows file is unsigned, so Windows may show a SmartScreen warning. Only download it from this project's GitHub Release page after the repository is published.

## ★ Highlights

- **Intel Arc ready on Linux:** detects Intel graphics, uses the available Vulkan driver, and applies a stable FIFO presentation profile for Arc systems.
- Launch KSA with the right mod loadout through StarMap when enabled.
- Browse nine curated community mods with version and compatibility notes.
- Six author-provided mod previews in Discover, available offline.
- Click a preview for a larger, credited image in the mod details.
- Missing previews fall back to a clear icon rather than a blank card.
- Back up your mod loadout and manifest before you make changes.

## Notes

The Windows file is unsigned and may show a SmartScreen warning. This is an independent community tool, not affiliated with RocketWerkz or Ahwoo. KSA and community mods are not included.
